# ADR-001 — Baseline Tecnológico y Arquitectura de CALLEFITS BY DANNI

## Estado
Aprobado (Baseline Oficial v1.1)

## Contexto
CALLEFITS BY DANNI inicia como una marca de ropa deportiva femenina de alta calidad y precio accesible. Requiere una plataforma web de alto impacto visual, excelente rendimiento móvil, indexación SEO de primer nivel y un flujo comercial que derive a WhatsApp. Además, la arquitectura debe permitir evolucionar hacia cosméticos, cuentas de usuario y pagos automatizados sin rehacer el proyecto.

## Decisión
Se aprueba de manera definitiva el siguiente stack tecnológico:

1. **Frontend & Framework:** Next.js 15 (App Router, React Server Components prioritarios) con TypeScript en modo estricto.
2. **Estilos y Design System:** Tailwind CSS configurado con variables CSS semánticas (tokens de color desacoplados) y componentes modulares de shadcn/ui.
3. **Micro-interacciones:** Framer Motion (restringido a transiciones suaves y respetando `prefers-reduced-motion`).
4. **Backend, Datos y Storage:** Supabase (PostgreSQL 16, Supabase Storage CDN y Supabase Auth con Row Level Security).
5. **Validación y Tipos:** Zod para esquemas de datos y validación de formularios/acciones.
6. **Checkout Inicial:** Generador dinámico y contextual de mensajes hacia WhatsApp Business.
7. **Testing:** Vitest para pruebas unitarias/integración y Playwright para pruebas E2E.
8. **Infraestructura:** Git/GitHub para control de versiones y Vercel Edge Network para hosting y CI/CD.

## Consecuencias
### Positivas
- Máximo rendimiento y puntuaciones Core Web Vitals gracias a React Server Components.
- Cambio de identidad visual inmediato mediante edición de tokens en `globals.css`.
- Costo inicial de infraestructura $0 (tiers gratuitos de Vercel y Supabase).
- Autonomía total de la administradora para cambiar precios y fotos sin tocar código.

### Negativas / Mitigaciones
- Mayor disciplina requerida en el manejo de Server vs Client Components (resuelto mediante reglas estrictas en `AGENTS.md`).
- Dependencia del servicio de Supabase (mitigado mediante tipos TypeScript desacoplados y repositorio de datos modular).
